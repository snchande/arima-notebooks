Part one

What Arima Notebooks is

Before installing anything, here is the idea in a paragraph.

A notebook is a document where writing and working code sit side by side. You type a few lines, press a button, and the answer appears directly underneath. Change the lines, press again, and the answer updates. That quick loop is why notebooks are used everywhere from classrooms to research labs.

Arima Notebooks is a notebook that runs entirely on your own computer. There is no account to create, no subscription, and nothing is uploaded anywhere. When you close it, it stops. When you open it, your work is still there.

What makes it different

Eight languagesPython, JavaScript, TypeScript, Java, JShell, C#, F# and C++ all work in the same document. Most notebooks only do one.
Learn by comparisonAny piece of code can be shown side by side in a language you are learning, with notes explaining what changed and why.
40 lessons includedGuided tutorials from absolute basics upward, where every line of code is explained.
PrivateEverything runs locally. No telemetry, no cloud, no sign-up.
You do not need to know what a "language" is yet Think of them as different ways of writing the same instructions, each better at different jobs. Part four gets you running real code, and the built-in lessons take it from there.
Part two

Before you start

Two small things to know, then we install.

You will use the terminal - and that is fine

The terminal is a window where you type commands instead of clicking buttons. You will use it twice: once to install, once to start. You will copy and paste both times.

Windows Press the Windows key, type powershell, and open Windows PowerShell.
Mac Press Command + Space, type terminal, and press Enter.
Linux Press Ctrl + Alt + T, or find Terminal in your applications.
A black window with text is normal It is not an error. It is just waiting for you to type something.

What the installer needs

Arima needs Java to run. If you do not have it, the installer offers to fetch it for you - you do not need to find or install anything yourself beforehand.

Everything else is optional. Arima works without it; the extras simply unlock more languages later.

What the installer will do

  • Show you what it is about to do, and wait for you to say yes
  • Check what is already on your computer, and show you a list
  • Offer to install only what is missing, one item at a time
  • Download Arima Notebooks and prepare it
  • Tell you clearly when it has finished
Nothing is installed without your approval The installer explains itself first and stops for your answer. If you change your mind, close the window - nothing has happened yet.
Part three

Installing Arima Notebooks

One command. Copy the one for your computer, paste it into the terminal, and press Enter.

1

Open your terminal

Use the instructions from part two. Leave the window open.

2

Copy the command for your computer

On Windows - paste this into PowerShell:

> irm https://raw.githubusercontent.com/snchande/arima-notebooks/master/install.ps1 | iex

On Mac or Linux - paste this into Terminal:

$ curl -fsSL https://raw.githubusercontent.com/snchande/arima-notebooks/master/install.sh | bash

Paste with Ctrl + V (Windows and Linux) or Command + V (Mac), then press Enter.

3

Read what it tells you, then say yes

Before changing anything, the installer explains what Arima is, what it will install and where. It looks like this:

Windows PowerShell
DEPENDENCY CHECK ------------------------------------------------------------ [ok] Java java version "21" [ok] Git v2.51.0 [--] Node.js missing (optional) -- JavaScript cells [--] Python missing (optional) -- Python cells Install the missing pieces? [y/N]

Type y and press Enter to continue.

4

Wait for it to finish

It works through one item at a time and prints a tick beside each. This usually takes a few minutes, mostly downloading. You will see:

INSTALLATION COMPLETE Run arima start to open Arima Notebooks.
If it stops with an error Nothing is broken. The installer remembers how far it reached - run the same command again and it carries on from where it stopped rather than starting over. If it stops in the same place twice, part six tells you how to get help.
Curious before committing? Add -CheckOnly (Windows) or --check-only (Mac and Linux) to the end of the command. It shows you everything it would do, then stops without changing a thing.
Part four

Your first notebook

Arima is installed. Let us run something.

1

Start it

In the same terminal window, type:

> arima start

Your web browser opens automatically at localhost:8585. That address means "this computer" - the page is not on the internet, it is being served by your own machine.

Stopping and starting Close the browser tab whenever you like - your work is saved. Type arima stop in the terminal to shut it down, and arima start to bring it back.
2

Make a new notebook

Click + New Notebook. Give it a name - "My first notebook" is fine - and choose Python as the language. Python is the friendliest place to begin.

3

Write one line and run it

Click into the empty box - a cell - and type:

print("Hello from my own computer")

Now press Shift + Enter (hold Shift, press Enter). The answer appears just below the box:

Cell 1 - Python
print("Hello from my own computer") Output Hello from my own computer

That is the whole loop. Everything else is a variation of it.

4

Try something that calculates

Add another cell, type this, and run it the same way:

price = 4.50 cups = 3 print(f"Total: {price * cups} pounds")

You have just stored two values, multiplied them, and printed a sentence. Change cups to 10 and run it again - the answer updates instantly. That is the loop that makes notebooks useful.

Where to go next

Click Browse and open Arima Tutorials. Start with Python 101. Every line of code in the built-in lessons is explained, so you are never left guessing what something does.

Part five

Useful things to know

A short reference for your first week.

Commands you will actually use

arima startStart Arima and open it in your browser
arima stopShut it down
arima statusCheck whether it is running, and what it found on your computer
arima registerMake notebook files open in Arima when you double-click them
arima helpShow everything it can do

Inside a notebook

Shift + EnterRun the cell you are in
+ CodeAdd a new cell for code
+ MarkdownAdd a cell for notes and headings, not code
BrowseOpen your notebooks, or the 40 built-in lessons

Where your work is kept

Notebooks are ordinary files on your computer, named after the notebook itself and ending in .anb. You can copy, back up, or email them like any other file. Nothing is hidden in a cloud account.

If something looks wrong

Browser did not openGo to localhost:8585 yourself.
"arima is not recognised"Close the terminal and open a new one. Newly installed commands only appear in new windows.
Page will not loadCheck it is running with arima status, then arima start.
A cell shows red textThat is an error message, not damage. Read the last line - it usually names the problem. Fix the code and run it again.
You cannot break it Nothing you type in a cell can harm your computer or lose your work. If a notebook gets into a muddle, restart it from the toolbar and run the cells again from the top.
Part six

Getting help

If you get stuck, saying so helps the project.

Arima Notebooks is open source and still young. If the installer fails, or something does not behave as this guide describes, please report it - a clear report from someone new is genuinely more valuable than one from someone who already knows the workarounds.

How to report a problem

  1. Go to github.com/snchande/arima-notebooks/issues
  2. Click New issue
  3. Say what you were doing, what you expected, and what happened instead
  4. Copy in any red or error text from the terminal

If the installer itself fails, it prints the exact address to report to, along with details about your computer. Copying that block into the issue is the single most useful thing you can do.
